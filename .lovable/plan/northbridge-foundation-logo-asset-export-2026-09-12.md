# Northbridge Foundation logo asset export

## Deliverables
Create a downloadable brand package based exactly on the logo currently used on the site: the bridge-and-sun mark paired with the Fraunces wordmark in the existing deep-teal brand color.

The package will include:
- Primary-color full wordmark: editable SVG and transparent high-resolution PNG
- Primary-color logo-only mark: editable SVG and transparent high-resolution PNG
- White full wordmark and logo-only mark: SVG and transparent PNG
- Black/single-color full wordmark and logo-only mark: SVG and transparent PNG
- Square favicon set: SVG plus transparent PNG sizes suitable for browsers and social profiles
- A compact usage/reference sheet with colors, typography, clear-space guidance, and file recommendations
- One ZIP containing the complete, clearly named asset set, plus direct downloads for the principal files

## Fidelity and production quality
- Reconstruct the existing mark from its original vector paths rather than tracing a screenshot.
- Preserve the current 30:30 mark geometry, spacing, proportions, and the Fraunces 600/400 wordmark styling.
- Convert production wordmarks to editable vector outlines so typography remains exact without requiring a font installation; also include a live-text source SVG for future copy editing.
- Use transparent canvases throughout and export large PNG masters without upscaling raster artwork.
- Keep print-ready SVG viewboxes clean, with no embedded bitmap, clipping artifacts, or unnecessary metadata.

## Visual quality checks
- Render and inspect every exported variant against light and dark backgrounds.
- Check edge margins, alignment, transparent backgrounds, color consistency, small-size legibility, and pixel dimensions.
- Compare the primary lockup against the site logo and refine any spacing or proportion mismatch.
- Re-open the final ZIP manifest to confirm every requested format and variant is present.

## Site consistency
Replace the generic browser icon with the new square Northbridge mark and point the site metadata to it, without changing the visible page design.
